## 「1円のズレ」が積み重なると

給与計算担当者なら一度は経験したことがあるはず——毎月の端数処理で生じる数円、数十円のズレ。

「誤差の範囲」と軽視しがちですが、これが**未払い残業代の請求**に発展するケースが増えています。

時効は**3年**（2020年4月以降）。従業員50名の企業で月500円の未払いが続けば、3年間で**90万円の請求**になりえます。

## 法律が定める端数処理のルール

### 原則：1分単位で計算

労働基準法では、労働時間は**1分単位**で計算することが原則です。

つまり、「15分未満は切り捨て」「30分単位で切り上げ」などの処理は、原則として**違法**です。

### 例外として認められている端数処理

通達（昭和63年3月14日基発第150号）により、以下のケースのみ例外的に認められています。

| 処理の単位 | 認められる条件 |
|---|---|
| 1ヶ月の合計時間の30分未満切り捨て・30分以上切り上げ | ○ 認められる |
| 1時間あたりの賃金単価の端数（50銭未満切り捨て・50銭以上切り上げ） | ○ 認められる |
| 日単位・週単位での切り捨て | × 認められない |

## 実務でよくある計算ミス3選

### ミス1: 時間単価の計算で「年間所定労働時間」を間違える

```
【誤った計算例】
月給 25万円 ÷ 月の所定労働時間 160時間 = 1,562.5円

【正しい計算】
月給 25万円 ÷ 年間所定労働時間(1,960時間) ÷ 12ヶ月 = 1,581.6円
→ 端数処理後: 1,582円
```

> 注意: 祝日数や年間暦によって所定労働時間が変わるため、毎年確認が必要です。

### ミス2: 日単位で端数を切り捨てた後に集計

NG例：
```
月曜: 残業1時間20分 → 1時間（20分切り捨て）
火曜: 残業1時間45分 → 1時間（45分切り捨て）
合計: 2時間（本来は3時間5分）
```

OK例：
```
月曜: 残業1時間20分 → 80分
火曜: 残業1時間45分 → 105分
合計: 185分 → 3時間5分 → 3時間（5分切り捨て）
```

### ミス3: 深夜・休日割増の計算を忘れる

割増賃金の種類と最低倍率:

| 種類 | 最低倍率 |
|---|---|
| 時間外労働（月60時間以内） | 1.25倍 |
| 時間外労働（月60時間超） | 1.50倍 |
| 深夜労働（22時〜5時） | 1.25倍 |
| 休日労働（法定休日） | 1.35倍 |
| 時間外 + 深夜 | 1.50倍 |

## まとめ

端数処理のルールは「一度正しく設定すれば、あとは自動化できる」部分です。

まず自社の給与計算システムの設定を確認し、日単位での切り捨てが行われていないかをチェックすることから始めましょう。不安な場合は、社会保険労務士への相談をお勧めします。
