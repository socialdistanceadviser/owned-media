## 「30人の壁」とは何か

スタートアップやベンチャー企業で必ずと言っていいほど起きる現象——それが「30人の壁」です。

20名以下のころはうまく機能していた「代表が全員を見る」「評価は感覚と信頼関係」というやり方が、30名を超えると突然機能しなくなります。

典型的な症状:
- 評価基準が人によってバラバラになる
- 「あの人はなぜ昇給したの？」という不満が出始める
- マネージャーが評価に自信を持てなくなる
- 優秀な人材が「評価されていない」と感じて退職する

## なぜ30名が転換点なのか

心理学の研究によれば、人間が「個人として深く知ることができる人数」は約150名（ダンバー数）とされていますが、実務上の「マネジメントできる範囲」は大きく異なります。

```
1〜15名: 代表・リーダーが全員を個人として把握可能
15〜30名: 把握は可能だが、公平な評価が困難に
30名〜: システムなしでの運用は破綻
```

## スケールする評価制度の設計原則

### 原則1: 評価軸を「行動」で定義する

「主体性がある」という評価項目は機能しません。代わりに:

```
【悪い例】
- 主体性がある
- コミュニケーション能力が高い

【良い例】
- 上司に指示される前に課題を発見し、解決案を提示している
- 週次ミーティングで他部門への影響を考慮した発言ができている
```

### 原則2: 等級と評価を分離する

多くのベンチャーが犯すミスは「評価 = 給与」の直結です。

```
推奨構造:
等級（スキル・責任レベル） → 給与レンジを決定
評価（期間内のパフォーマンス） → 昇給額・インセンティブを決定
```

この分離により、「等級が上がらないと給与が上がらない」という閉塞感をなくせます。

### 原則3: 1on1をデータ化する

評価の公平性を高める最強の武器は**日常の1on1記録**です。

n8nとNotionを連携させた1on1サポートシステムの構成:

```
[Googleカレンダー: 1on1予定]
→ [n8n: 前日リマインド + アジェンダ生成]
→ [Notion: 1on1メモ入力]
→ [n8n: 評価期間終了時に自動集計]
→ [評価シートに定量データを挿入]
```

## まとめ

30人の壁を越えるための人事評価制度は、**複雑である必要はありません**。

シンプルな行動ベースの評価軸 + 日常の1on1記録のデータ化 + 年2回の評価サイクル。この3つを正確に実装することが、フェーズ初期には最重要です。

AIツールは「評価の補助」として使い、最終的な判断は必ず人間が行うことを忘れずに。
