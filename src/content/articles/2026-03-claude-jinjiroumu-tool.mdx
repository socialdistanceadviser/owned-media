## 「人事への問い合わせ」という時間泥棒

中規模企業の人事担当者が1日に受ける問い合わせの内訳を調べると、驚くべき結果が出ます。

「有給の残日数は？」「育休はいつから取れる？」「交通費の上限は？」——これらの**社内規定で答えられる質問**が全問い合わせの約40〜50%を占めているという実態です。

Claude APIで社内規定QAボットを構築した結果、**月間250件の問い合わせが120件に減少**した事例を紹介します。

## システム構成

```
[Slack / LINE WORKS] ← 従業員からの質問
         ↓
    [n8n Webhook]
         ↓
  [Claude API + 社内規定テキスト]
         ↓
    [回答生成 + 出典表示]
         ↓
  [Slack / LINE WORKS に返信]
```

## 実装の核心：プロンプト設計

人事労務QAボットで最も重要なのは**プロンプト設計**です。

```python
SYSTEM_PROMPT = """
あなたは{会社名}の人事規定に関するQAアシスタントです。

## 役割
従業員からの人事・労務に関する質問に対して、提供された社内規定に基づいて正確に回答します。

## 重要なルール
1. 回答は必ず「社内規定の第○条」「就業規則 第○章」などの出典を明記する
2. 規定に記載がない内容については「規定に定めがないため、人事部にご確認ください」と答える
3. 法的解釈が必要な複雑な質問は「詳しくは人事部または社労士にご相談ください」と案内する
4. 個人の具体的な状況（例：「私の場合は?」）への回答は行わない

## 提供された社内規定
{rules_text}
"""
```

## Claude APIとの連携コード（Python）

```python
import anthropic

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

def answer_hr_question(question: str, rules_text: str) -> str:
    """社内規定に基づいてQAに回答する"""

    message = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1024,
        system=SYSTEM_PROMPT.format(
            company_name="株式会社サンプル",
            rules_text=rules_text
        ),
        messages=[
            {
                "role": "user",
                "content": question
            }
        ]
    )

    return message.content[0].text

# 使用例
rules = open("company_rules.txt", encoding="utf-8").read()
answer = answer_hr_question(
    question="育児休業は子どもが何歳まで取得できますか？",
    rules_text=rules
)
print(answer)
```

## n8nでのSlack連携

n8nのHTTP Requestノードを使って、SlackのメッセージイベントをトリガーにClaude APIを呼び出す設定:

```json
{
  "trigger": "Slack Message Received",
  "condition": "channel == #hr-questions",
  "action": {
    "node": "HTTP Request",
    "method": "POST",
    "url": "https://api.anthropic.com/v1/messages",
    "headers": {
      "x-api-key": "{{$credentials.anthropic_key}}",
      "anthropic-version": "2023-06-01"
    }
  }
}
```

## 精度を上げる3つのテクニック

### 1. 社内規定のチャンク分割

規定が長い場合、全文をコンテキストに入れると精度が下がります。質問に関連する章のみを抽出して渡す設計にしましょう。

### 2. 回答の信頼度スコアリング

```python
# プロンプトに追加
"回答の最後に、この回答の根拠の確かさを「確実（規定に明記あり）」「やや不確実（推測を含む）」「不明（人事確認推奨）」で表記してください。"
```

### 3. フィードバックループの設置

回答に「役に立ちましたか？」ボタンを設置し、低評価の質問をSlackに通知する仕組みを作ることで、ボットの改善サイクルを回せます。
